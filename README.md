# HappyMap

A mobile app that shows you interesting or useful places around you, and how far they are.

Tap a button, and HappyMap surfaces nearby points of interest based on your current location — with distance shown for each place, so you know what's actually worth the walk.

## Tech Stack

- **React Native / Expo** — cross-platform mobile app
- **Google Places API** — nearby place data
- **TypeScript**
- Custom hooks + services architecture for location and places data

## Status

Working MVP, solo project.

## Getting Started

```bash
npm install
npx expo start
```

Requires a Google Places API key — see `.env.example` for the expected environment variables.
